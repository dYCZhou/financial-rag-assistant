财报RAG项目蓝图与验收标准
版本：2026-08-18完成态

1. 项目目标

把比亚迪、宁德时代、贵州茅台、美的集团、中国移动2023—2025年共15份年度报告构建为证据优先的问答知识库。回答必须限定公司和年度、引用原文与PDF物理页；不提供投资建议、估值或股价预测。

2. 已完成链路

PDF登记与SHA-256校验 -> 逐页解析 -> 页面图像人工抽查 -> baseline/structured切分 -> BGE向量索引 -> 中文BM25 -> 加权RRF -> 财务口径重排 -> 证据门禁 -> DeepSeek生成 -> 引用校验 -> Streamlit展示 -> 冻结题评测与人工复核。

3. 分阶段验收门槛

数据：公司×年度完整，官方来源可追溯，PDF可打开、正文可提取，页数/大小/哈希登记。
解析：封面、目录、正文、合并财务表和全部异常短页完成人工抽查；review JSON记录结论和限制。
切分：两种策略均生成可追溯chunk，保留document_id、股票代码、年度、章节和PDF页。
索引：记录数正确，真实查询可执行，15份共存且document_id/股票代码/年度过滤不串库。
检索：每份独立冻结15题，首次盲评原始报告保留；Recall@5最低80%，替代证据单独人工审计。
生成：真实API逐题执行，答案事实、单位、年度、口径和引用人工核对；错误和拒答如实记录。
产品：只开放检索验收通过报告；文档切换清除旧回答；错误不暴露堆栈；推荐问题必须来自该报告人工验收通过题目。

4. 当前验收结果

15份报告全部达到retrieval_quality_accepted。全项目225道逐报告冻结题均有真实RAG和人工复核记录。新增11份165题最终Recall@5为86.67%—100%，165/165人工正确，0拒答、0API或管线错误；冻结标准页命中164/165，剩余1题命中有效替代证据。

共享BGE索引：baseline 4,863条，structured 5,591条。当前自动化测试：62项通过。

5. 设计原则

- 冻结题、答案和标准页不得因调优而回写。
- 首次盲评与修复后复测分别保存。
- 结构更规整不等于检索更好，逐报告选择最佳策略。
- count()不等于索引可用，必须做真实查询和过滤验证。
- 有近邻不等于有证据，低相关问题必须拒答。
- 页面正文可隐藏引用编号，但后端原始答案与引用对象不得丢失。
